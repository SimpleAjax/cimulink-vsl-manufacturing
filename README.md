# Cimulink Manufacturing VSL

Standalone static landing page for Cimulink's manufacturing operational-visibility VSL.

## Deploy to Vercel

Import this repository as a Vercel project. No build command or output directory is required: Vercel serves the root `index.html` directly.

For a custom subdomain, add `manufacturing.cimulink.com` in the Vercel project domain settings and create the CNAME record Vercel provides at the DNS provider.
